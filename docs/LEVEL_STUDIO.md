# 作者关卡工坊

只看已做好的模型时，直接打开[法师鸭3000块](../preview/wizard-duck.html)或[柴犬400块](../preview/shiba.html)，再点直接试玩，无需走以下制作流程。

仅作者本机使用，未放入玩家界面。使用同一预览服务，执行 `npm ci`、`npm run preview:build`、`npm run preview:serve`，打开 `http://127.0.0.1:4179/preview/level-studio.html`。默认只绑定本机；不是公开后台。可导出文件到另一台电脑使用。

## 工作流程

1. 上传PNG/JPEG/WebP参考图（≤2MB、≤4096×4096）。不会上传网络或自动变成3D；Meshy未配置，生成按钮不可用。
2. 导入自包含、无贴图、无动画/骨骼/扩展的静态GLB（≤12MB、展开≤5万三角面），或用内置鸭/兔/熊完整实体样例。外部网址、缺失缓冲区、过量访问器、重复场景根等在加载前拒绝。纹理首版不采样，请导出不带贴图、使用材质颜色的模型。
3. 选择目标200–800块、最多2–6色、轻松/标准/挑战（批次长度14/8/4）。颜色最多值不是强制凑足，单材质可能只有一色。数量为目标，实际数量由轮廓与规则采样决定并显示，不随机删块。分块在独立任务中运行，修改参数会取消，超过20秒会停止并提示简化。GLB必须封闭；开放/过薄/不合法实体会提示失败。多个独立封闭实体取并集。
4. 点击生成，切换完整实体/积木结果，拖动旋转、滚轮缩放。每色账本应一致；通路验证通过后导出关卡JSON或试玩。
5. 试玩在正常游戏页面隔离加载，暂停/旋转/连点仍可用；不增加正常图册或解锁进度。再玩按钮仍为同一制作关卡。普通游戏地址没有 `studio=1` 时不加载制作数据。
6. 保存工程下载包含参考图、设置和已生成关卡的JSON；恢复可直接试玩。GLB不打包，需要作者另行保存，再调整实体时重新选择。单独导入关卡JSON不会冒充恢复了对应实体。

## 规则与导出

一发命中清一个同色积木，核心只做音画反馈。各色初始弹药总量等于各色积木数，发射中计入在途，暂存保留余弹。四槽失败仍可能由槽位/顺序造成，不能通过少配弹药制造失败。固定颜色和供应，不按输赢临时修改。

关卡版本1：`{version:1,level:...,palette?:[hex...]}`，包含细胞、四队列、初始视角和可复放参考解（旧solution或新长弹量replay）；最多6000块/400胶囊、关卡JSON2MB，输入白名单字段与逐色总量验证后真实复放通路。导出不含凭据、参考图、脚本。制作工程单独为projectVersion1，不是可直接给玩家加载的关卡。

## 验证与后续

共享规则/体素/导入测试及浏览器制作流程已覆盖。现有10关都可用四槽无奖励参考路径通关；这不是任意顺序必胜保证，也不是真人难度结论。体素采样与材质归并会损失小细节，不等于精确曲面切割。

尚未接Meshy任务API、在线资产库或正式关卡发布后台。以后配置账号时将密钥放本机服务端环境变量，再接生成/轮询/下载/失败恢复；不要发到聊天或Git。浏览器GLB导入不代表Cocos运行时导入已实现，Creator/微信/iPhone仍待验证。

当前成品法师鸭使用离线3000格与长弹量，工坊自主生成滑块仍为200–800；可导入已验证的HD关卡试玩。游戏供应显示四行，仅第一行可点。

法师鸭当前使用pacing=remaining的先快后慢时钟；数据可选该字段，未标记仍旧时钟。成品带4套已验证乱序池，开局/重开/刷新换一套，局中固定；导出的单个关卡JSON只保存一套有效关卡，不自动带整个池。重建池使用 `npm run build:wizard-shuffles`，正常预览构建会核对指纹并实际复放全部候选。
