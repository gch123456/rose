# 鸭子自救与逃离鸭货命运：主题设计增补

日期：2026-11-11（北京时间）。用户已确定剧情与全鸭角色方向；以下场景、敌人、表现手法和命名仍为建议，不是游戏实现或完整获批实施方案。

## 已确认的新方向

- 剧情从“保卫家园”改为鸭子自救，逃脱被怪物变成熟食、鸭锁骨、鸭舌等鸭货的命运；失败呈现被变成这些食物。
- 用户随后明确：可玩角色统一为**不同职业的鸭子**，集中“逃离变鸭货”的主题。此前鸡/鸭/鹅职业候选已被取代。
- 多角色、通关解锁新角色、近战战士/法师/射手与武器特效保留，具体名称、初始角色和解锁顺序仍待定。
- 竖屏单手移动、自动攻击、自动小成长＋场内走位二选一与专注自身割草保留；开局次数及离线/广告规则按既有决定，不因换剧情改变。

## 一句话概念与表达建议

“一群不想成为鸭货的鸭子，拿起武器，杀出一条生路。”
建议可爱像素外形配荒诞逃生喜剧，危机感来自追捕与临近出口的压力；失败用变形笑点表达。用户未要求写实屠宰或具体受众评级，本轮不据此承诺审核/发行结果。
开局可用极短情境交代被贴上菜名/出货标签，鸭子挣脱后立即开始战斗；不让长对话延迟第一次移动和击杀。
项目代号继续使用 GoDuck；“鸭命要紧”“拒绝上桌”等仅为命名候选，未做可用性核查或正式更名。

## 自救故事怎样接到现有玩法

| 环节 | 候选表达 | 玩法边界 |
| --- | --- | --- |
| 开局 | 鸭子挣脱待加工队列，捡到自己的职业武器 | 立刻进入移动/自动攻击，不新增逃生 QTE |
| 怪潮 | 捕鸭怪、追捕机器或厨具怪围堵 | 沿用清群＋可读威胁的敌人职责；具体造型未定 |
| 成长 | 收集散落的谷粒、获得临时能力与武器形态变化 | 经验仍服务简单易懂的成长，不把同伴变成经验食材 |
| Boss | 守住出口的追捕头目或巨型厨具怪 | 战胜 Boss 在结算表现突围；不要求即时发现新出口或再增加限时跑图 |
| 胜利与解锁 | 逃离本区域并在短结算中解救另一只职业鸭 | 通关解锁角色的机制保留；不自动变成局内护送/守笼血条玩法 |
| 失败 | 本局鸭子被怪物变成鸭货，显示菜名/包装标签 | 仍是本局失败，不永久删掉角色或已有解锁 |

可采用厨房/加工厂作为场景候选，亦可采用怪物的魔法厨房；用户尚未指定敌人为真人厨师、工厂或魔法世界，不能将这些写成用户确认。
厨房道具可作为武器外形候选：战士鸭挥锅铲/羽翼刃、法师鸭发射水泡、射手鸭发射谷粒；无需一次重做全部技能逻辑，具体武器造型另定。

## 失败表现建议

- 建议 1–2 秒可跳过的短变化：烟雾/印章或包装合盖→菜品标签→本局成绩和再开入口；不展示切割过程。风格为本轮建议，尚未确认或制作。
- 菜名可先采用“鸭锁骨”“鸭舌”“卤鸭”等少量卡片；选择可与关卡/Boss 关联，避免仅随机菜名掩盖真正死因。
- 例如显示“本次出品：鸭锁骨”，旁边仍写清“被夹子怪冲刺命中”，帮助玩家知道下把怎么改进；文案只是候选。
- 反复失败允许快速跳过或缩短表现，不延迟重开。第一版不新增菜谱收集、失败奖励、额外复活广告或永久死亡系统。
- 已有通关解锁与存档保留；剧情失败不改变既有开局扣次规则，也不再次惩罚性扣次数。

## 场景与美术候选

先做一个区域的完整战斗与胜负表现。后续可讨论备餐区、传送带区、出货区：分别承载基础追捕、方向压力和混合围堵；总关卡数仍未定。
传送带、卤锅和包装机可先作为背景或 Boss 造型，不因场景名称默认加入强制位移、烫地板、计时装箱等新系统。若增加环境机制，需另行设计。
首套角色小样改为一只职业鸭；旧鸡/鹅图、农场场景与“家园守住了”等文案需列入迁移清单，而非在未验证工具的情况下批量重做。
特效继续按近战斩击、法术范围、远程弹道区分，烹饪装饰不可遮挡命中反馈和敌人危险预警。
