# 私有制作工具实施计划

用户已确认作者专用、暂不接生成服务，先做工具。按已讨论完整3D路线实施，不把参考图冒充重建结果。设计见同日spec。

1. 共享规则与生成（独立工作）：先测试每色守恒、全10关通路、密度参数和坏JSON；改清块为一发一块，通用makeLevelFromCells构造四列可解队列，完整规则校验可导入关卡。提高旧模型细分密度，坐标整数、实际shape匹配，图册ID不变。共享API契约见执行记录。
2. 网格体素化（独立工作）：先测试封闭几何、数量边界、材质色、错误恢复所需纯接口；从受限自包含GLB的三角形采样生成整数坐标Voxel，数量目标200–800、2–6色，返回实数与诊断。无网络生成。
3. 作者网页：独立/studio入口，上传参考图/GLB、原实体/分块旋转预览、参数/账本、导出版本化JSON、工程保存/恢复；未配置AI明确禁用。内置样例可走通全流程。
4. 游戏导入：通过sessionStorage一次性测试关卡传递，严格验证后加载；测试局不解锁/记录正常图册，正常默认入口仍10关。
5. 校验：规则测试/类型、体素几何测试、真实浏览器制作→导出→试玩、原有输入/旋转/图册/奖励回归；修复新规则下旧核心测试的预期，保留防双命中。密度性能和采样数设硬上限。
6. 独立代码审查；更新STATUS/DESIGN/ROADMAP/CHANGELOG/本次archive；明确未接Meshy/未Creator真机；显式暂存并非强制同步main。

分工避免共享编辑：规则代理拥有Game/Levels/Animals/Difficulty及其tests/evaluator；体素代理拥有新Voxelizer与几何tests；父代理拥有网页/工具/build/package/docs。代理不得提交。

实施结果：上述1–6已完成并验证，详见archive同日记录；Meshy配置/服务端生成明确后续。独立审查发现的问题已修复；大模型生成使用可取消/20秒超时Worker。
