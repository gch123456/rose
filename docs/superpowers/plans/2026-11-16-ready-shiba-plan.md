# 直接生成柴犬与一键试玩

用户否定多步实体制作流程，要求由助手生成、只需一两步。按此前柴犬素材语境，直接生成原创简洁卡通柴犬，明确是程序造型而非付费图生3D或原照片精确重建。操作：打开看实体→点击试玩。无需上传/选格式/手动配弹。

1. 共享隐式实体：身体/头/尖耳/口鼻/四腿/卷尾平滑并集、有限配色；细网格提取单个封闭表面，导出小型无贴图GLB。测试连通/封闭边、颜色/尺度与GLB结构。
2. 同一实体直接实心采样约400块，并用既有生成/编码/解码校验四槽无奖励通路，严格每色弹量=积木。生成静态可下载JSON，保持正式图册隔离。
3. 一个独立成品预览页，默认显示完整实体，提供直接试玩按钮与可选积木预览/GLB下载，不能再要求用户走工坊配置。既有工坊仍可使用，不改变默认10关。
4. 真实浏览器预览/旋转/一键跳转/实际小段射击验证、完整参考通路与既有规则测试，检查模型正侧面截图，独立审查；记录并同步main。

不加入外部模型生成API/付费服务，不覆盖用户原始GLB。无新项目依赖。Creator/微信真机仍待验收。

后续用户追加 model (1).glb，要求600–700块。已沿用同一成品页结构新增650块法师鸭，原模型轻量预览，实际轮廓/UV采样、实心填充、守恒队列、参考通路与浏览器验证。1–4任务及追加均完成，证据见同日ready-models记录。
