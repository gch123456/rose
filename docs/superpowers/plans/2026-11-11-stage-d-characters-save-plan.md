# 阶段 D 实施计划：三职业解锁 + 版本化存档

日期：2026-11-11。设计依据：`docs/superpowers/specs/2026-11-11-core-gameplay-v02-design.md`（三职业表、解锁顺序、存档边界）。上一阶段：`2026-11-11-stage-c-boss-plan.md`。

## 目标

1. **存档**（新模块 `assets/scripts/SaveData.ts`，纯 TS 可 Node 测试）：
   - 版本化格式 `{ version: 1, wins, unlocked, current }`；解析失败/版本不符回退默认档，不崩溃。
   - 解锁链：射手首次胜利 → 解锁战士；战士首次胜利 → 解锁法师；失败不回退；重复结算不重复发奖。
   - 保存当前职业；原子保存 = 单次写入调用，先内存后落盘。
2. **战士鸭**：近战主武器「羽翼/锅铲斩」18 伤害/0.75 秒，射程 100、正面 120°，每敌一击；25 秒分支「宽斩」（220°）/「重斩」（射程 125、90°、1.6D、间隔 ×1.3）；120 秒进化：宽斩两层全周弧（各 0.8D）、重斩 1.6D 斩 + 0.96D 延伸震波（同一次攻击不重复命中）。
3. **法师鸭**：水泡 12 伤害/0.9 秒，射程 260、爆裂半径 65，每爆每敌一击；分支「爆裂」（半径 105）/「连锁」（半径 50，跳 100 内未命中过的敌人）；进化：爆裂两段各 0.8D、连锁首目标 1.6D + 4 跳各 0.8D。
4. **进化预算**：每轮单目标合计伤害上限 = 该分支进化前的 1.6 倍；只有一个目标时能实际打满。
5. **菜单**：主菜单选角（未解锁置灰显示锁）；胜利结算展示新解锁提示；辅助装备（泡泡圈/飞羽）三职业通用。

## 不做

- 不做次数/广告/多设备同步（保持待设计）；冷启动直接回主菜单丢弃未完成局。
- 不改 Boss、刷怪、成长数值（C 阶段已定）。
- 不新增美术素材（职业区分用现有像素鸭 + 武器名/弹道颜色/特效）。

## 风险

- 战士近战在 150 秒刷怪节奏下的强度未知（100 射程、每敌一击），数值是调参起点，实玩后可调。
- 链式跳目标选取需确定性（按距离排序）保证测试稳定。
- localStorage 在预览与真机行为一致但容量有限，存档体积极小（<200B）不构成风险。
