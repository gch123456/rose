# 连点修复、全角观察与微信图册实施

日期：2026-11-16（北京时间）。起始提交：bafce63ad4e5c743e925c6d3951c55dd48e33505。分支：codex/album-orbit（起初为连点修复分支，后按用户追加范围调整）。用户要求继续修复，并追加通关图册、区分访客/登录、上下观察和默认自动旋转；随后明确微信登录。

## 实施与约定

1. 发射弹量更新会重建供应按钮，破坏尚未结束的按下/松开；装填动画也能遮住下一颗。保留供应/暂存/锁定槽按钮身份，只更新内容；装饰动画不参与点击。真实触屏/鼠标按下跨过发射刷新、连续四次装填均通过。
2. 模型XYZ旋转采用Rx(pitch)Ry(yaw)，上下±90°，初始pitch .24弧度，8°/秒自动yaw。首次手动操作停止自动；暂停/奖励/图册冻结。球、半球、圆柱、盒、楔形均改解析3D射线。闭盒壳通过自由空间证明确认死局，无法证明的曲面混合封闭保守不判败，避免细缝误判；复杂死局和难度指标仍待算法调节。
3. 图册按唯一level/model ID记录首个完成时间，访客保存在本机，账户缓存和待同步按服务端不透明ID隔离。登录合并访客成就并保留云端已有项，网络异常保存待同步；实际通关自动点亮并展示程序模型3D缩略图。测试关不计入正常收藏。
4. backend/采用Java21、Spring Boot4.1.2、H2文件存储，包含官方code2Session、摘要会话、账号隔离、图册合并/完成/注销；没有生产假登录入口。客户端只拿不透明ID与Bearer，不接触AppSecret/session_key。浏览器没有wx.login时诚实提示访客模式；测试模拟仅在测试工具中。
5. 本机使用校验下载的JDK21，仅通过命令指定，不改系统Java8。代码和运行说明入库，JDK、数据库、Maven产物、凭据不入库。Cocos组件及wx.login/wx.request桥已提供，但没有Creator/真实微信/iPhone验证。
