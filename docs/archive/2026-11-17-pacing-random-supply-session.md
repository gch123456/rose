# 剩余量变速与随机四行供应

2026-11-17（北京时间）。起点main 5506c4c，分支codex/pacing-random-supply。用户要求积木多时消除快、少时慢，以及下方4行随机排列。当前法师鸭仍3000格、6色、40颗67–88发，各色总弹量不变。

## 实施

- 当前法师鸭标记pacing=remaining，根据真实活块比例平滑二次曲线：满量发射间隔0.045秒、飞行0.10秒，收尾逐步到0.18/0.36秒。每颗弹丸保存创建时duration，SVG/Cocos弹丸按自身时钟画，不因后续剩余量变化而跳位；仍每槽最多一枚在途、一发一块。
- 未标记pacing的默认10关/旧柴犬/旧导入仍保留原0.14/0.28时钟，避免破坏历史复放。新字段白名单/实际复放校验同步。
- 40颗完整洗牌再分4列，不只是交换整列。离线生成4套种子固定、颜色混合的候选（20261118/20/21/23），每套都用真实四槽、只选供应列头/跨转面模拟通关，没有广告或运行时改色/补弹。保持相同细胞、胶囊ID、数量与每色配额。
- 打开新局/重开/刷新时从4套中随机选，排除上一套；暂停、续关、局中不重排。前排可点、后三排预览，原四行与小屏保持。
- 成品页只传递基础关卡和候选池，游戏启动后统一选取与严格解码，不选两次。启动字段在全部校验后一次提交，坏调色板/候选不会留下可在重开时复活的随机状态；最近索引存储失败不阻止合法游戏。
- 构建校验候选指纹与每套实际复放，陈旧候选不打包。正常预览构建读取已提交候选；需要重新生成时执行npm run build:wizard-shuffles，再构建预览。
