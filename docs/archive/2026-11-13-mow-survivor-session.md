# 2026-11-13 割草机制重制会话（万剑救鸭）

## 需求与用户确认

用户反馈「做的太差太差了」，给出抖音参考（疯狂的土豆先生《仙侠风肉鸽割草小游戏》短链 `v.douyin.com/96nhqC0cfTI/`），询问能否修改设计和玩法。按 `AGENTS.md`「新玩法与较大行为变化先澄清、评审设计再实现」先做澄清，用户明确三点：

1. **强化割草机制，主题还是拯救鸭子不变**（用户自定义回答，非照搬仙侠换皮）。
2. **背景偏亮色、Q 版像素风**（与参考封面的暗黑竞技场相反，故不照搬暗色）。
3. **旧玩法保留为经典模式**（可切换）。

起始提交：`12400b1`（传送阵救援），分支 `main`。

## 参考调研

抖音网页端只返回分享页错误占位与封面图，视频本体需 App 内观看，故以封面 + 标题为准，未声称看过完整视频。封面可读信息：近黑竞技场、成团黑影怪（红色血条）、中心角色一次放射数十道金色/白色细长剑气、满地绿色发光魂珠、红色伤害数字、白色领域光环、底部六格技能栏。抽取出的「割草感」要素是**怪潮密度 + 多路自动弹幕 + 经验/升级构筑 + 高密度反馈**，而非特定仙侠题材。本轮只迁移机制与信息密度，视觉按用户要求走亮色 Q 版像素。

## 设计与实施

- **新增 `assets/scripts/SurvivorGame.ts`**（纯规则层，无 Cocos 依赖）：90 秒一局、72 秒 Boss、100 秒截止；成团刷怪（`spawnPack` 每次 2–4 只、上限 190）、四路自动输出（万剑诀扇形飞剑 / 护身剑阵 / 引雷符 / 金光领域）、绿色魂珠吸附拾取、升级三选一（14 项升级池、可堆叠、跨级连续发牌、15 秒自动选保底）、暴击与伤害数字、粒子/特效/屏震数据、波次播报、Boss 冲撞与召唤、击退自动折算救鸭数、通关加成。
- **`assets/scripts/GoDuck.ts`** 改为双模式入口：默认割草模式，菜单一键切到经典模式（`EscapeGame` 原逻辑与 76 项既有测试完全不动）。新增「晴日牧场」亮色像素视觉系统 `Q`：静态晴空／方块云／阶梯远山、滚动棋盘草地与像素小花、常驻传送阵、像素鸭拾取物、金色剑气三层描边＋菱形剑尖、护身飞剑、雷劫、魂珠、伤害数字标签池、玉牌 HUD（生命／经验／波次／救鸭数）、六格技能栏、升级三选一卡片、传送阵入场演出与结算大数字。屏震只作用于世界层。
- **网页试玩**：`preview/renderer.js` + `tools/build-preview.mjs`，用 Node `stripTypeScriptTypes` 把同一份 `SurvivorGame.ts` 内联生成自包含 `preview/mow.html`。支持鼠标/触摸摇杆、WASD、1/2/3 选卡、Enter 开局与 `?auto=1&fast=N&choice=1` 调试快进。
- **输入**：升级卡点按或数字键选择，选卡期间冻结世界与摇杆；经典模式的暂停、静音、开局次数与占位广告逻辑保持不变。
- **存档**：`SaveData.ts` 未改，v2 兼容；割草模式首胜同样走既有解锁链（御剑鸭 → 剑阵鸭 → 引雷鸭）。
- **数值迭代**：初版每 0.30 秒 7 把飞剑、怪潮 7–20 只/秒，截图验收发现密度不足；改为每 0.26 秒 10 把（射手）/6 把（其他）、怪潮按小队成团 6–22 队/秒、飞剑射程 360、敌人速度上调，16 秒模拟从 44 只存活提升到 103 只、击退 199→321。
