- 四个基础槽＋第5/6个分别解锁的本局槽。浏览器和Cocos代码均明确标注“模拟广告”，取消不发奖；没有接微信真实广告或分享奖励。
- 发射事件与命中分离，0.28秒共享飞行时间，目标/连锁范围预留防重复，飞行中保留槽位且不提前判死局。浏览器弹丸从槽位真实屏幕位置发出，绘制弹道、炮口和命中反馈。
- 满槽且所有方向无匹配目标、无在途子弹才失败。每局先限一次模拟续关；保留已清除部分、队列、余弹、角度和已解锁容量，将胶囊放入可独立取回的暂存区，不挡住原供应前排。全部弹药耗尽时不提供无效清槽续关。
- 共享层奖励票据绑定运行实例，重开/新关卡后的旧票据、重复回调不发奖；模拟期间冻结玩法。

- Cocos同步形状网格、6槽、暂存/模拟奖励与弹道代码，保留旧场景及2D配置；没有手写scene/meta，没有Creator/微信构建验证。

## 独立审查与修复

独立审查未发现共享奖励、预留或关卡路径缺陷，指出两项实际问题：小屏全HUD＋暂存会裁切供应/页脚；视效在新发射当帧额外累计dt，导致子弹早于真正命中消失。两者均先用浏览器断言复现失败，再分别用短屏重排、绑定共享flightId/time修复并通过。另修正Cocos飞入动效仍用旧4槽坐标的问题。作者补充楔形面朝向回归后修复内向法线，避免仅显示内侧。
