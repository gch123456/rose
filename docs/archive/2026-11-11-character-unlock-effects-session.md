# 2026-11-11 多角色、通关解锁与武器特效设计

北京时间。起始提交：`4307702b8989c58bbff50b19ef49433461b77240`。本轮按用户要求增补设计，不实施游戏功能。

## 用户需求与已确认方向

用户要求角色可以多个，通关后解锁新角色，支持近战战士/法师/射手等风格及武器特效，并加入设计。
沿用家禽主题、竖屏单手、只有移动和自动攻击、自动小成长＋场内走位二选一。
此前一角色小样只是制作顺序建议，不再可解释为产品只有一个角色；完整验证应含通关解锁另一角色与重玩。

## 设计增补与建议边界

新增 [角色设计增补](../superpowers/specs/2026-11-11-character-unlock-effects-design.md)，区分用户确认需求与候选角色/解锁表。
建议优先固定动物职业，候选鹅战士/鸭法师/鸡射手，通过攻击范围、弹道、空档和成长分支区分走位；具体映射未获确认，不将新武器名称冒充现有代码。
建议首次完成指定关卡解锁指定角色，同条件只发一次；候选先从鸡入门，再解锁鹅和鸭，具体关卡数量/顺序仍待定。
补充自动攻击无需手动瞄准、近战安全距离、结算提示、存档可靠性、重复事件处理及武器发出/轨迹/命中/进化的音画反馈要求。
用户没有要求额外以广告/分享/付费解锁角色，本轮不自动增加这些条件；也未批准全面更强的新角色或复杂职业技能键。

## 操作与验证

干净 main 获取远程更新后读取当前实现/设计/待办，核对三动物目前可直接选、无解锁存档、进化只翻倍伤害。
更新设计、协作基线、状态、待办、开放问题、持久化清单与更新记录；检查本轮 Markdown 相对链接和 Git 差异。
未改 TypeScript、场景、资源、广告或平台 SDK，未运行游戏/引擎/真机测试，未安装工具或生成素材。
按既有授权同步 main，提交结果以 Git 历史和本次交付回复为准。
