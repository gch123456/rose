# 微信救援台和精准命中

2026-11-18（北京时间），起点 `ccd5f54`。作者反馈旧版模型缺少立体轮廓，白块的实际清除位置难以识别，底部的椭圆加图标过于简陋。

- 恢复固定在模型坐标上的亮暗面，使用同一色相与封闭边界，并用蓝绿色舞台增加浅色块的背景对比。保留分区网格、两关色号和弹药配额。
- 依据在途弹丸的真实体素编号显示黑边白描角，依据清除事件用金色描角短闪，显示位置随模型转动。使用既有遮挡查询隐藏被挡住的标记，绘制和存储的命中特效均有上限。弹丸对应弹药颜色，并使用短拖尾，发射／结算速度与目标选择规则维持原有行为。
- 底部重做为有计数窗、金属卡扣和立体鸭形壳的装填模块，发射基座有炮口和装填色窗。保留四行及仅前排可选。

229 项测试、严格类型检查与三种竖屏视口的 Cocos Web 验证通过。模拟实际点击白色弹药，确认同一色的目标描角、命中短闪、消除中拖动和松手恢复。两关均完成画面检查。

微信开发者工具成功编译预览。微信预览包位于 `build/wechat-rescue-workbench`。公众平台版本未覆盖，iPhone 和 Android 微信真机待验收。
