## 当前已实现

### 规则层 `assets/scripts/EscapeGame.ts`

- 新增常量 `RESCUE_PICKUP_RADIUS=55`、`RESCUE_BATCH=2`、`RESCUE_INTERVAL=9`、`RESCUE_MAX_ACTIVE=8`、`RESCUE_OPENING_COUNT=3`、`WIN_RESCUE_BONUS=12`，以及 `StrayDuck` 结构。
- `start()` 在传送阵周围（世界原点）放 3 只待救小鸭；之后每 9 秒在玩家附近补 2 只，场上最多 8 只；`time >= bossAt(150)` 停止刷新，场上已有的仍可捡。
- 拾取沿用谷粒/食物的「走过即拾取」机制（半径 55）：产生 `rescue` 事件与 `rescue` 特效，**不加经验、不计击退**，不是护送对象也没有血条。
- `rescued`（实际撤离）/ `rescueBonus`（胜利 +12，失败 0）/ `totalRescued` getter；`start()` 全量重置。
- 未改移动、自动攻击、刷怪、成长、Boss、解锁与存档规则。

### 表现层 `assets/scripts/GoDuck.ts`

- 点「开始逃跑」后播放 1.35 秒传送阵入场演出：三层旋转符环＋刻度＋中心亮盘＋鸭子由光中放大现身，两端柔和淡入淡出；演出期间**冻结 `game.tick`**（不计时、不刷怪、不掉血），隐藏 HUD 文字，banner 显示「传送阵启动 · 鸭子入场」。
- 世界原点 `(0,0)` 常驻传送阵地标（同心环、旋转刻度、呼吸光），随相机滚动，只在视口内绘制。
- 待救小鸭由 Graphics 绘制（暖黄头＋薄荷身＋橙嘴＋脚下光环，轻微浮动），不依赖异步资源加载；拾取时弹出 1 秒上浮提示「+N 只鸭经传送阵撤离」及薄荷色卡片，`rescue` 事件配独立提示音（720Hz）。
- HUD 第一行常驻「救出 N 只」；结算面板以「N 只鸭」为主数字，配「免于上餐桌」与明细（撤离数 / 突围加成 / 等级 / 击退 / 谷粒 / 武器）；结算演出 banner 也带数字，失败文案为「仍有 N 只被你送走」。
