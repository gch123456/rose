# 微信星灯码头与连消节奏

2026-11-18（北京时间），起点 `a0f2d41`。作者希望优化模型背景、装填和高频消除音画，适当用环绕效果，上移设置，四个基础槽也要有完整体验。

- 雨衣鸭是黄昏救援站，法师鸭是星灯码头。渡灯与水纹每秒更新最多 15 次，效果绘制在模型背后。上移营地和关卡的设置齿轮。
- 缩短装填动效，加入弹药同色炮口短闪。按实际命中间隔形成连消，5／12／20 次及后续每 20 次触发分前后两层的光轨。原创音效分装填、命中三档、连消和高连消。既有同色五连显示仍会出现。
- 四槽都满且暂时打不到时，操作提示换为转面找同色。法师鸭出现确切死局且有可用弹药时，免费暂存按钮成为主选项。每局一次，弹药与进度保留。
- 232 项测试与严格类型检查通过。法师鸭四个随机开局经规则复放均用四槽清完 4500 块，无扩槽与续关，且开局前排均可命中。Cocos Web 三种屏幕验证了设置、实点装填和拖转，440×956 另验证 20 连消、音效调用及前后光轨。此处验证音效触发，真机听感及复玩仍需试玩。

微信开发者工具已成功预览构建，目录为 `build/wechat-rescue-streak`。公众平台旧版本未覆盖。
