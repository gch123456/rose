# 微信鸭鸭救援界面

2026-11-18（北京时间），起点 `main` 的 `77b37b3`。作者要求把弹药做得圆润立体、用齿轮取代暂停按钮、重做营地和关卡背景、适配手机，并改善放大拖转模型时的颜色表现。

- 营地采用救援插画、任务卡和宽按钮。两关采用不同色调的池塘舞台，前排弹药采用亮面、阴影、鸭子图形及形状符号。后排保留四行预览规则与问号。
