# 微信雨衣鸭引水救援

2026-11-25（北京时间），起点 `07d160a`。用户确认做引水冲壳，强调汇流加成、持续游玩的爽感和原创视觉。

- 新默认微信试玩用同一只雨衣鸭，支持两路独立流水、逐段冲壳、双水到达后解锁排洪、重玩与本机图鉴。营地有原版试玩入口。
- ImageGen 背景提示围绕雨后温室水池、陶土、荷叶、黄铜管、中央留空。运行时用 Cocos 生成水带、泡沫与陶壳碎块，保留立体拖动。釉面明暗烘焙在顶点颜色中，以适配当前微信引擎配置。五段音效由可重复脚本合成。
- 第一版一关，后续关卡取决于首次试玩对水路是否看得懂、汇流和排洪是否有足够区别、是否主动重玩。

- 原版可在营地退出到引水模式。跨模式切换会结束旧对局，图鉴与独立声音开关共享本机存档。
- 回读图鉴时，Creator 3.8 会把旧的 Map 和 Set 展开写法降级为拼接，导致读取到迭代器。改用 `Array.from` 后，在新原生场景实例里验证了救援记录可读取。

背景使用内置 ImageGen，项目资源为 `assets/resources/color-clear-release/water-garden.jpg`。生成描述为雨后清晨的鸭鸭救援温室，风格为精致的手工陶瓷微缩景观。画面竖向 2:3，略微俯视，边缘为湿润的桉叶、玻璃温室和黄铜管，中间三分之二保留柔和的青绿色空间，前景为有淡泡沫和荷叶的池水。图中没有角色和文字。

254 项测试、Cocos 严格类型检查、440×956 网页触屏全流程、原版场景回读图鉴和来回切换均通过。微信开发者工具为 `build/wechat-rescue-water-final` 生成预览码，预览包为 3.2 MB。iPhone 与 Android 真机流畅度和触感待验证。
