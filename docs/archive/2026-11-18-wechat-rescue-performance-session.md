# 微信旋转与消除性能

2026-11-18（北京时间），起点 `main` 的 `7952b16`。用户反馈 iPhone 17 Pro Max 在消除与旋转时卡顿。

- 法师鸭舞台由 4505 个渲染组件降为 42 个，包括 37 个积木分区网格和 5 个五官细节。只生成外露面，清除时只重建受影响的分区及必要邻区。碎片复用现有绘制层并限制同时显示的数量。
- 发射按颜色索引选择候选，复用当前姿态下的遮挡判断。旋转和发射不再触发全弹药面板重画，弹药格状态变化时才更新对应显示。保留逐块消除、快消节奏和 4500 块模型。
- 226 项测试与 TypeScript 检查通过。Cocos Web 在 Mac Chrome 软件 WebGL 的 390×844 视口中对照旧包，法师鸭自动旋转与连续消除两个采样段的第 95 百分位帧间隔均约从 100 ms 降至 50 ms。另用触摸输入验证发射中拖转和松手一秒后恢复旋转。帧时间采样仅用于本地对照。
- Cocos 3.8.8 微信构建和微信开发者工具预览编译通过。包位于 `build/wechat-rescue-fast`，预览码位于 `build/preview-codes/duck-rescue-fast.png`。公众平台已有开发版 0.1.0 未覆盖，iPhone 真机帧时间待复测。
