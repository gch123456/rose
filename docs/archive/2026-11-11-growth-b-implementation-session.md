# 阶段 B：自动成长、装备掉落、群伤与进化

日期：2026-11-11（北京时间）。设备：原型开发 Mac，Creator 3.8.8。
起始提交：`1321f9f90a40828b08e5039b9d7ff1a73dddb436`，分支 `main`；接手时工作区干净，fetch / ff-only 后无新增远程提交。

## 用户反馈与执行范围

用户反馈 A 虽可玩，但没有升级/装备掉落/群伤，也没有继续玩的欲望；在说明 B 的自动升级、走位二选一、辅助和进化后，用户要求“你做吧”，并询问像素图制作工具。本轮直接落实已讨论的 B；像素素材仍用此前选定的 PixelLab，另一台设备的接入待办保留，没有在本机安装、登录或扣费生成。

## 设计与实施决定

- 沿用 V0.2 的职业主武器＋一个辅助，150秒射手成长实验；无暂停读卡。
- 谷粒实际加经验，10＋4×(等级－1)升级，最高12；每级主武器线性增伤8%，偶数级加4%攻速。满级谷粒计分，不无限回血。
- 25秒装备分支：长线五目标穿透或三向散射；70秒辅助：泡泡圈范围群伤/减速或飞羽穿透。装备是场内二选一掉落，非旧版随机装备库。
- 世界标记安全找点、0.8秒后可拾取，靠近22选中；15秒未取自动装备长线/泡泡圈。选择期间普通战斗继续，暂停会冻结所有游戏计时，停止新特殊预警，既有预警仍生效。拾取保护0.6秒并推开近敌。
- 120秒保证进化：双脉冲长线或五向风暴，单体每轮伤害预算保持进化前1.6倍；双脉冲相隔0.08秒便于辨认。辅助单独按等级强化后的D计算。
- 加锅盖锁地预警、后段刷怪密度与45/100秒后首次击杀补给；经验、装备、食物分开保存；致命伤同一步食物不复活。
- 界面新增等级/经验条、构筑、成长预告、装备标记/短说明、升级/装备/进化文字与不同轮廓/合成音。
- 主场景说明通过已核实项目身份的MCP更新并保存；保留场景与脚本UUID，旧Game测试作历史对照。

实施选择：Creator和MCP固定在当前项目目录，直接沿用已干净同步的工作区完成实际预览；没有额外复制场景/meta的工作区。仅更新本任务文件，发布前再校验远程。

## 验证与修正

- 先新增12项成长测试，确认旧实现因缺少功能失败；实现后修正Node strip-only不支持参数属性的写法。散射测试明确中央目标更近，避免等距目标的浮点排序影响其测试目的。
- 独立只读复核发现边角落点要求120而设计只需90，且仅试首点；新增失败回归后改为遍历候选对、90下限。另加入双脉冲时间错开的失败回归并实现。最终旧6＋A7＋B14，共 **27项通过、0失败**。
- Creator TypeScript no-emit **0错误**；场景/脚本检查、保存与资源刷新分别核实。网页初次加载仍显示旧缓存，显式刷新对应脚本后重新加载，才进行以下B验证。
- 网页真实键盘/点击试玩：拾取散射成功、三向弹道可见；谷粒拾取后自动升级到Lv.2/Lv.3，不弹卡；另一局未取标记后长线/泡泡圈自动装备。
- 完成一局真实150秒网页战斗（途中有手动暂停）：120秒自动出现双脉冲进化提示与蓝色分离弹道，150秒进入实验结算；最终 **Lv.5、210击退、65谷粒、5格生命**。重开后恢复 **Lv.1、0/10经验、基础谷粒弹、辅助待掉落、150秒**。浏览器错误日志为空。该结果是开发者验证，不是目标玩家测试或正式通关。
- 前一局在约71秒因锅盖接触死亡，验证真实死因；未据此单独下调难度。主武器分支的不同取舍需要后续实际观察。
- 规则诊断机器人（3固定种子，追经验/装备并避近怪）：首升约11.28–15.60秒，死亡58.82/128.70/116.52秒，其中一局到达进化。仅排查可达性，不作为真人乐趣/胜率结论。
- Node存在原有模块类型自动识别警告，测试通过；本轮不改Creator项目整体模块模式。
