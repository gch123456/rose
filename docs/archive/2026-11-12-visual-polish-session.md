## 本次设计决定（已实施）

- 视觉主题「暖夜加工厂」：低饱和深蓝夜色 + 暖金 / 薄荷点缀，让像素鸭、谷粒、弹幕保持最高对比度，长时间注视不刺眼。
- 渲染分层（节点顺序即层级）：`Backdrop`（静态渐变、光晕、远景管道货架剪影）→ `Ground`（世界地砖、警戒带、发光出口门）→ `World`（动态对象）→ 像素精灵 → `HudFrame`（卡片 / HUD / 菜单 / 结算）→ 文字 → 按钮。
  - 静态氛围只在视口变化时重画一次；地面每帧只绘制视口内格子，装饰由确定性噪声生成，不闪烁。
- 配色集中在 `GoDuck.ts` 顶部 `PAL` 常量便于换肤；`c()` 缓存 Color 实例；`s` 以 640×1120 竖屏为基准等比缩放，横屏 / 矮屏不会越界。
- 入口：品牌徽章复用 `duck/idle-south` 像素鸭、卡片化菜单、三张职业卡（选中态）、暖金主按钮、漂浮谷粒与呼吸光晕。
- 游戏内：加工厂地砖与格栅、边界斜纹警戒带、出口门、心形生命、卡片化顶部状态栏 / 经验条 / 底部进度胶囊、半透明摇杆。
- 结算演出移到 HudFrame 层，配柔和压暗与胜负对应光晕。
- 顺手修正：暂停态按钮显示「继续」而非「暂停」，静音态显示「静音」；声音按钮与暂停按钮同显隐，菜单态不再残留。
