# 首份GLB体积检查与低面数副本

2026-11-16（北京时间）。起点main `eb7820b1d11b1590906c59856d9ff7acaafb995b`。用户提供本机Downloads/model.glb，询问一百多MB如何处理。已检查工作区/远程，不修改源文件，不将大型素材上传Git。

## 实测与处理

- 源GLB2：170,214,560字节，5,603,588三角面，1个网格/节点/材质，1张JPEG贴图4,848,527字节，无动画、扩展或外部贴图。
- 体积主要来自几何。使用临时目录安装的glTF Transform4.5.1/meshoptimizer，weld→simplify（ratio0.00535,error0.02）→prune，保留UV/贴图，未给游戏新增依赖。
- 输出Downloads/model-lite-43k.glb：6,945,644字节、43,192面、1张原贴图，独立检查GLB长度/统计一致，实际Chrome WebGL前侧面渲染成功。约减少96%体积和99.2%面数；有损简化，不保证细节无变化。
- 原模型与副本均已实际渲染对比：大幅简化导致毛发细节明显变粗糙，不作为最终美术成品。整体柴犬轮廓可识别，但毛发/胸口/尾巴存在薄片和碎片，不能凭能渲染就当作封闭实体。当前工坊还拒绝贴图，此文件是带贴图预处理副本，不宣称已经生成可玩关卡。
- 原文件未改，副本和预览图保留在作者Downloads。大模型/贴图不进入Git，跨设备请单独传输素材；Git仅同步本记录。
