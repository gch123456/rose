## 引擎模块差异

- 裁剪前：`engine.json` 没有 `modules` 配置，引擎按**默认全量模块**打包，无法逐项列出，不能当作 0 个模块。
- 裁剪后：显式列出 **15 个** → 2d, affine-transform, animation, audio, base, custom-pipeline, gfx-webgl, gfx-webgl2, graphics, intersection-2d, particle-2d, profiler, tween, ui, ui-skew
- 其中 `ui-skew` 是 Creator 3.8.8 构建时自动补入的依赖模块，非人工添加；配置已被编辑器规范化并排序。
