# 游戏设计基线

归档日期：2026-11-10（北京时间）。状态：首个可玩原型，数值仍需试玩调优。

## 当前可试玩：V0.2 阶段 C（2026-11-11）

在 B 的 150 秒成长后接入出口 Boss「巨型捕鸭夹」，默认入口为 180 秒完整局；规则与验证见 [阶段 C 归档](archive/2026-11-11-stage-c-boss-session.md)、[实施计划](superpowers/plans/2026-11-11-stage-c-boss-plan.md)。

- 150 秒停普通刷怪，清退存活敌人不发奖励；地上谷粒/食物保留可拾取，生命/等级/构筑保留。
- Boss 900 生命、半径 32，八等角候选（半径 200）优先屏幕上方且中心 ±780 内；1 秒预告直接显现，入场不攻击、不可受伤，计入最后 30 秒。
- 冲撞与三发扇形弹交替：冲撞 0.9 秒直线预警锁定方向后 420 速度冲 0.45 秒（触地图边缘提前停），接触扣 2 格；扇形弹 0.8 秒预警后发 -25/0/25° 三发（速度 150、射程 450、碰撞半径 8），扣 1 格，发出后固定 2.2 秒攻击阶段并清掉剩余弹丸；每招结束 1.2 秒不移动不攻击、可正常受伤的恢复窗口。
- Boss 不受击退/减速，不同时叠两招，阶段内不加小怪，死亡不掉落。
- 必须实际击败 Boss 才赢；180 秒仍存活判负「出口被封锁」；同一步玩家归零优先判负；胜负只提交一次。失败/胜利均为可立即跳过的占位结算面板＋真实死因。

完整数值与 D（职业解锁/存档）见 [V0.2设计稿](superpowers/specs/2026-11-11-core-gameplay-v02-design.md)。次数/广告未实现；除射手鸭像素图外其他图形仍程序占位。玩法是否好玩、目标手机输入和可读性仍待真人验证。

## 原阶段 B 记录（2026-11-11）

用户反馈 A 缺少升级、装备、群伤和继续玩的动力，已要求落实上一轮提出的 B：自动小成长、分支/辅助掉落二选一、保证进化。当前 Home / GoDuck 使用 EscapeGame，旧 Game 与 3＋3/鸡鸭鹅/暂停升级保留作历史对照。

- 一局150秒成长实验，只有移动输入，升级/选择/进化均不停顿；死亡结束，时间满显示实验完成，不发通关奖励。
- 捡谷粒加经验，升级门槛10＋4×(当前等级－1)，最高12；每级伤害在基础12上线性＋8%，偶数级攻速线性＋4%。满级谷粒仅计分。
- 25秒主分支掉落：长线单弹最多5敌；散射三向各0.8D、每弹1敌、每轮单敌最多2弹。
- 70秒辅助掉落：泡泡圈每1.5秒半径90、0.35D群伤，减速35%持续1秒；飞羽每1.2秒射程300、0.6D穿透2敌。
- 两次装备各15秒超时自动装备长线/泡泡圈；世界标记90–150距离，安全找点、0.8秒可拾取，靠近22即选中。无落点每0.25秒重试；处理期间停止新特殊预警，既有预警继续。拾取给0.6秒保护并推开近处敌人，不暂停。
- 120秒自动进化：长线变双脉冲（各0.8D），散射变五向（各1.28D、同轮单体最多两弹）；单体每轮预算为进化前1.6倍，辅助独立使用等级强化后的D。
- 手套/夹子沿用A；55秒起每15秒锅盖替换普通名额，最多2只。140生命、速度35，160内每5秒锁地面点、0.9秒预警半径60压盖。特殊同一刷怪时点重合时优先夹子，不积欠重发。
- 刷怪0–20/20–50/50–90/90–120/120–150秒每秒2/3/4/5/6只，最多160活敌。保留视野外出生/可见0.7秒保护/90°退路、移动边界±850。
- 45/100秒后的首次击杀各掉一次食物，回1生命，满血转3经验；经验260上限合并，装备与食物单独保存。掉落限制±830，死亡当步食物不复活。
- 界面显示生命、等级/经验条、当前主/辅助、下次成长与选择保底倒计时；升级/装备/进化有短文字、轮廓特效与可关闭合成声音。

完整数值与后续C/D见 [V0.2设计稿](superpowers/specs/2026-11-11-core-gameplay-v02-design.md)。当前无Boss、职业解锁/存档、次数/广告；射手鸭已接入八方向像素静态/行走，其他图形仍程序占位；PixelLab在本机已接通并生成 [首张射手鸭造型候选](art-samples/2026-11-11-shooter-duck/README.md)，未接入游戏，方向/动画及最终风格仍待确认。玩法是否好玩、目标手机输入和可读性仍待真人验证。

以下旧实现数据只用于历史对照，不作为当前入口说明。

## 目标与核心循环

最新玩法方案见 [V0.2 第一关重设计](superpowers/specs/2026-11-11-core-gameplay-v02-design.md) 与 [对应实验卡](playtests/2026-11-11-v02-experiments.md)。用户已接受设计/验证方法并授权修改玩法；本轮策划提出主武器＋辅助、25/70 秒两次选择、120 秒进化、150＋30 秒完整局和同一关的职业解锁顺序，**具体规则仍待评审，尚未实现或试玩**。下面的原型数据是旧 Game.ts 的历史实现，不是 V0.2 新规则。

最新主题（2026-11-11）：鸭子自救，避免被怪物变成熟食/鸭锁骨/鸭舌；失败呈现变成鸭货。可玩角色统一为不同职业的鸭子，取代此前鸡鸭鹅保卫家园的方向。用户随后接受可爱像素/荒诞喜剧、夹子怪冲刺/锅盖怪堵路、出口头目、胜利解救职业鸭和约 1–2 秒可跳过的鸭货结算，中文名暂定《鸭命要紧》，代号 GoDuck。具体数值/场景仍待定，见 [主题设计](superpowers/specs/2026-11-11-duck-escape-theme-design.md)。
旧 Game.ts 的历史循环是：走位 → 自动攻击 → 击杀掉谷物 → 拾取升级 → 随机三选一 → 精英宝箱 / 进化 → 三分钟后挑战 Boss → 胜负结算。旧农场与家园文案、鸡/鹅可选角色尚未迁移，不代表新主题已实现。

玩家始终专注自身走位和割草，没有鸡舍生命和护送 / 防守目标；这一玩法边界在改为自救剧情后继续保留。此前家园仅为背景的决定见 [接续记录](archive/2026-11-11-repository-sync-session.md)，剧情随后已被本次决定取代。其余数值仍为原型实现，需试玩验证。

最新体验方向（2026-11-11）：用户反馈停下来选择 Buff 鸡肋，希望简单易懂、不停顿、更早割草，并保留通关挑战；现已明确选择“自动小成长＋走过去二选一”。首套音画按上一轮彩色像素风与基础反馈建议推进。**下面的暂停三选一保留在旧 Game.ts；当前 A 不弹升级，B 的二选一尚待接入**。确认与范围见 [本次记录](archive/2026-11-11-pixellab-setup-approved-direction-session.md)；具体出现次数、数值和美术规格需设计/小样验证。

## 原始设想与原型取舍

| 内容 | 原始设想 | 当前实现 |
| --- | --- | --- |
| 装备位 | 6 武器＋6 被动 | 3 武器＋3 被动，先验证三分钟成长 |
| 怪物增长 | 按分钟、指数增长 | 分段增加，数量封顶，避免性能失控 |
| 进化 | 宝箱随机出现机会 | 满级武器＋对应被动，拾箱优先进化 |
| 操作 | 只走路，无攻击键 | 保留；额外提供暂停及升级选择 |
| 胜利 | 时间满出现 Boss，击败获箱 | 180 秒进入 Boss 战，最多 90 秒；获箱为结算提示，无局外库存 |

## 角色与装备

### 新增已确认方向（2026-11-11，尚未实现）

用户要求多个可玩角色、通关解锁新角色、近战战士/法师/射手等风格与对应武器特效；仍保持竖屏单手移动、自动攻击。
角色/职业应体现攻击方式与走位差异；角色已统一为不同职业的鸭子，初始职业、解锁关卡与武器成长为候选，见 [多角色设计增补](superpowers/specs/2026-11-11-character-unlock-effects-design.md)。
上一轮聚焦一只动物的建议仅可作为制作顺序，不再作为产品角色数量限制；需验证通关解锁后用新角色重玩。
下表仍是旧 Game.ts 的起始装备，并非新职业表；当前三个角色均可直接选，没有角色解锁或持久化。

| 角色 | 初始武器 | 区别 |
| --- | --- | --- |
| 鸡 | 啄击 | 最近敌人单体打击；鸡的啄击间隔乘 0.8 |
| 鸭 | 水波 | 周期范围伤害、减速 |
| 鹅 | 鹅鸣 | 周期范围伤害、击退非 Boss 敌人 |

武器上限 5 级，被动上限 3 级。辣椒每级伤害＋20%；小靴子每级速度＋12%；谷物袋每级拾取距离＋35。
进化配方：啄击＋辣椒；水波＋谷物袋；鹅鸣＋小靴子。武器必须满级，对应被动至少 1 级；进化后伤害翻倍，暂未制作独立进化动画。
装备槽满后不提供新的同类装备，只升级已有项。可选项不足三种时显示实际数量；全满时经验转升级和回血。

## 战斗数值（以 Game.ts 为最终依据）

- 初始生命 100，移动速度 175，地图移动边界 ±850。
- 升级经验需求：7＋当前等级×4；升级选择期间暂停战斗和计时。
- 普通敌人掉 2 经验，精英掉 12 经验和宝箱；拾取距离 45＋谷物袋加成。
- 每分钟每波数量依次 1 / 2 / 3；刷怪间隔随时间缩短，最低 0.13 秒；最多 160 敌人、260 掉落。
- 为减少空等，首秒刷怪距离 100，后续普通刷怪距离 420，精英 / Boss 默认 500。
- 45 / 90 / 135 秒刷精英；180 秒切 Boss 阶段并清理普通敌人。
- Boss 生命 1400，有冲撞预警，90 秒未击败则失败。
- 普通碰撞伤害 8，Boss 22；受击保护 0.65 秒；生命归零失败。
- 宝箱无进化资格时随机升级已有且未满级项，否则回复 25 生命。
