# GoDuck 首个可玩原型
Cocos Creator 3.8.8 / TypeScript。打开 assets/Home.scene 后预览。

WASD / 方向键移动；触屏按住拖动；Esc 暂停；升级可点击或按 1/2/3。
家园目前为故事背景，不承受伤害。三分钟生存后进入最多 90 秒的 Boss 战。
三种动物、三武器三被动，每种武器五级、被动三级。满级武器加对应被动后，精英宝箱优先进化。
45/90/135 秒刷精英，最多 160 个敌人、260 个掉落物。槽满后只给已有项升级。
初版使用程序绘图，无外部美术依赖；尚未接入局外成长、广告、音效、存档和平台 SDK。

规则测试：node --test tests/game.test.mjs
